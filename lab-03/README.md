# Lab 03

Các thuật toán mã hóa (Caesar, RSA, ECC) và API/Giao diện người dùng cơ bản.

## Cài đặt thư viện (Requirements)
Mở terminal trong thư mục `lab-03` và chạy:
```bash
pip install -r requirement.txt
```

## Cách chạy
1. Chạy API server:
```bash
python api.py
```
2. Chạy ứng dụng giao diện (UI) hoặc các mã hóa:
```bash
python ceasar_cipher.py
# hoặc
python rsa_cipher.py
# hoặc
python ecc_event.py
```
